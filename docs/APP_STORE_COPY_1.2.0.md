### What's New

```
ZeroNet Space 1.2.0 — a smoother gallery experience.

New
• Swipe left/right to switch between photos in full-screen preview.
• Search photos by file name.
• Multi-select photos and delete them in one batch.
• Swipe between file previews (PDF, documents).
• Unlock Unlimited Imports right from the import screen when you hit the free limit.

Improvements
• Cleaner video player controls: progress bar, playback speed, mute, ±15s.
• Zoomed images stay inside the screen bounds instead of being dragged off-screen.
• One-tap Retry when images/videos/files fail to load.
• Clear "Imported N items" confirmation after importing.
• Calculator login screen now adapts to landscape and different screen sizes.

Fixes
• Fixed photos not being swipeable between pages.
• Fixed occasional "product not found" when unlocking Unlimited Imports.
• Fixed a misleading error alert when the user cancels a purchase.

Zero network, zero tracking, no account — 100% open source. Your data belongs only to you.
```
